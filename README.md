# Tiny Reservoir Computing

Projet pédagogique open-source : construction d'une toute petite IA de langage avec **Reservoir Computing**.

## Objectif

Explorer une façon différente de construire une IA, à très petite échelle, de manière claire et progressive.

## Structure du projet

Nous avançons étape par étape :

1. Préparation des données
2. Création du vocabulaire
3. Construction du réservoir
4. Faire tourner le réservoir
5. Entraînement du lecteur
6. Génération de texte

## Comment suivre

Chaque fichier numéroté correspond à une mini-étape.
On ne passe à la suivante que lorsque la précédente fonctionne.
